# Práctica en Java — Calculadora Científica con Historial

Práctica que implementa una Calculadora Científica con 5 funciones avanzadas y registro dinámico de historial.

Estudiante: Alin Anabi  
Rama: aanabi/practicas/practica-calculadora

---

## Funcionalidades
1. Operaciones básicas (+, -, *, /).
2. 5 Funciones científicas: Potencia, Raíz Cuadrada, Seno, Coseno y Logaritmo Natural.
3. Historial de resultados con List y ArrayList.

---

## Compilación y Ejecución
```bash
cd practicas/practica-calculadora
javac Calculadora.java
java Calculadora
```

---

## Conclusiones
1. Uso de java.lang.Math para funciones avanzadas.
2. Manejo de colecciones dinámicas para almacenar el historial de resultados.
3. Validación defensiva de datos numéricos.
