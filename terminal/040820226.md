# Documentación de comandos utilizados

## 1. Listar archivos y directorios

```bash
ls -la
```

**Descripción:**
Muestra el contenido del directorio actual en formato detallado (`-l`), incluyendo archivos ocultos (`-a`), permisos, propietario, tamaño y fecha de modificación.

---

## 2. Cambiar al directorio `test`

```bash
cd test
```

**Descripción:**
Accede al directorio llamado `test` ubicado dentro del directorio actual.

---

## 3. Volver al directorio anterior

```bash
cd ..
```

**Descripción:**
Sube un nivel en la estructura de directorios, es decir, cambia al directorio padre.

---

## 4. Crear un nuevo directorio

```bash
mkdir programacion-avanzada
```

**Descripción:**
Crea un nuevo directorio llamado `programacion-avanzada`.

---

## 5. Entrar al directorio del proyecto

```bash
cd programacion-avanzada
```

**Descripción:**
Cambia al directorio `programacion-avanzada` para trabajar dentro del proyecto.

---

## 6. Inicializar un repositorio Git

```bash
git init
```

**Descripción:**
Inicializa un nuevo repositorio Git en el directorio actual, creando la carpeta oculta `.git`.

---

## 7. Abrir el proyecto en Visual Studio Code

```bash
code .
```

**Descripción:**
Abre el directorio actual como un proyecto en Visual Studio Code.

---

## 8. Verificar la versión de Vim

```bash
vi --version
```

**Descripción:**
Muestra la versión instalada del editor de texto `vi` (o `vim`) y sus características.

---

## 9. Verificar la versión de Nano

```bash
nano --version
```

**Descripción:**
Muestra la versión instalada del editor de texto `nano`.

---

## 10. Verificar la versión de Visual Studio Code

```bash
code --version
```

**Descripción:**
Muestra la versión instalada de Visual Studio Code.

---

## 11. Cambiar al directorio del proyecto

```bash
cd ucatec/programacion-avanzada/
```

**Descripción:**
Accede directamente al directorio del proyecto ubicado en la ruta especificada.

---

## 12. Consultar el estado del repositorio

```bash
git status
```

**Descripción:**
Muestra el estado actual del repositorio, indicando archivos modificados, preparados para el commit y archivos sin seguimiento.

---

## 13. Agregar el directorio `docs` al área de preparación

```bash
git add docs/
```

**Descripción:**
Añade todos los archivos del directorio `docs` al área de preparación (staging area) para el próximo commit.

---

## 14. Agregar el archivo README

```bash
git add README.md
```

**Descripción:**
Añade el archivo `README.md` al área de preparación.

---

## 15. Ver el historial de commits

```bash
git log
```

**Descripción:**
Muestra el historial de commits del repositorio con información como autor, fecha y mensaje.

---

## 16. Crear un commit

```bash
git commit -m "Mi primer commit"
```

**Descripción:**
Guarda los cambios preparados en el historial del repositorio utilizando el mensaje `"Mi primer commit"`.

---

## 17. Configurar el correo electrónico de Git

```bash
git config --global user.email "gaston.quelali@ucatec.edu.bo"
```

**Descripción:**
Configura el correo electrónico que Git utilizará para identificar al autor de los commits en todos los repositorios del usuario.

---

## 18. Mostrar la configuración de Git

```bash
git config --list
```

**Descripción:**
Muestra todas las configuraciones activas de Git, tanto globales como locales.

---

## 19. Configurar el nombre de usuario de Git

```bash
git config --global user.name "QuelaliUcatec"
```

**Descripción:**
Configura el nombre de usuario que aparecerá como autor de los commits.

---

## 20. Mostrar los repositorios remotos

```bash
git remote -v
```

**Descripción:**
Lista los repositorios remotos configurados, mostrando sus direcciones para operaciones de lectura (`fetch`) y escritura (`push`).

---

## 21. Renombrar la rama principal

```bash
git branch -M master
```

**Descripción:**
Renombra la rama actual a `master`. La opción `-M` fuerza el cambio incluso si ya existe una rama con ese nombre.

---

## 22. Agregar un repositorio remoto

```bash
git remote add origin https://github.com/QuelaliUcatec/programacion-avanzada.git
```

**Descripción:**
Asocia el repositorio local con un repositorio remoto llamado `origin` alojado en GitHub.

---

## 23. Enviar los cambios al repositorio remoto

```bash
git push -u origin master
```

**Descripción:**
Envía la rama `master` al repositorio remoto `origin`. La opción `-u` establece la rama remota como referencia predeterminada para futuros `git push` y `git pull`.

---

## 24. Mostrar el historial de comandos

```bash
history
```

**Descripción:**
Muestra el historial de comandos ejecutados en la terminal durante la sesión o almacenados por el intérprete de comandos.
